# 🔱 cybersec-notes

> *"Know the system deeper than the one who built it."*

A living archive of my cyber security journey: raw notes, lab write-ups, and lessons learned while breaking things (legally) and fixing them better.

## 📂 What's Inside

- **Fundamentals:** Networking, Linux, Windows internals, cryptography basics
- **Web Security:** OWASP Top 10, Burp Suite, common attack patterns
- **Offensive Security:** Recon, enumeration, exploitation, privilege escalation
- **Defensive Security:** Logs, SIEM basics, incident response notes
- **Labs & Write-ups:** TryHackMe rooms and walkthroughs

## 🎯 Mission

Build real, practical skills in cyber security and turn them into a remote career. Every note here is proof of work, not just theory.

## 🧭 Approach

1. Learn the concept
2. Practice it in a lab
3. Write it in my own words
4. Repeat until it becomes instinct

## ⚠️ Disclaimer

All content is for **educational purposes only**. Practiced only in legal environments like TryHackMe and my own labs.
